# PDFs publicados com o site

| Arquivo        | Obra                                                        | Páginas |
|----------------|-------------------------------------------------------------|---------|
| `naveira.pdf`  | *Colección de Ifá* — Roberto Naveira                        | 3.118   |
| `delgado.pdf`  | *Tratado Enciclopédico de Caminos de Ifá* — Yamel Delgado   | 3.089   |
| `verger.pdf`   | *Ewé — o uso das plantas na sociedade iorubá* — Pierre Verger | 618   |

Os PDFs ficam nesta pasta com os nomes usados pelo índice, pelo leitor e pelo GitHub Pages. As páginas
indicadas são a numeração **do arquivo PDF** (página 1 = primeira folha do arquivo). Se substituir uma
obra por outra edição, confirme que o número de páginas e a paginação continuam compatíveis.

Os três PDFs e o arquivo `assets/transcricoes.json.gz` são publicados junto com o site. As transcrições
estão segmentadas e vinculadas às páginas correspondentes; a página `transcricao.html` as carrega.
